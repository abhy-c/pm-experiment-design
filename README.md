# PM Experiment Design

A portable Codex and Claude skill for planning product experiments and evaluating evidence. It adapts the plan to quantitative tests, qualitative research, prototype or usability studies, and pilots. It avoids invented thresholds and unsupported causal claims.

## Install

Clone this repository into the skills directory for your assistant:

```sh
# Codex
git clone https://github.com/abhy-c/pm-experiment-design.git ~/.codex/skills/pm-experiment-brief

# Claude Code
git clone https://github.com/abhy-c/pm-experiment-design.git ~/.claude/skills/pm-experiment-brief
```

Start a new session so the assistant can discover the skill. See [SKILL.md](SKILL.md) for its instructions.
